Tentang Platform AstroLife

AstroLife adalah platform web integratif yang dikembangkan untuk mengenalkan, mengeksplorasi, dan mengaplikasikan konsep-konsep astronomi modern dan etno-astronomi ke dalam kehidupan sehari-hari.

Teknologi & Metodologi yang Digunakan:

  • Backend Web: Python dengan Flask (Modular Blueprint Architecture).
  • Web Scraping: BeautifulSoup4 & Requests untuk kalender fenomena langit dari in-the-sky.org dengan mekanisme caching.
  • Prakiraan Cuaca: Integrasi Weather API untuk penghitungan Sky Quality Feasibility Score.
  • Machine Learning & Analisis Data: Scikit-learn (Linear Regression tren cuaca, K-Means Clustering, Lexicon Sentiment Analysis).
  • Komputasi Kalender & Falak: Penyatuan kalender Masehi, Hijriah Aritmetis, Jawa Mataraman, Jyotiṣa, serta hisab waktu salat dan Rasydulqiblat.
  • Antarmuka Modern: HTML5, Tailwind CSS, Lucide Icons, dan Chart.js.
